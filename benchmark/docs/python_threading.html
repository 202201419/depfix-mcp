threading module¶

Thread based parallelism.

threading.active_count()

Returns how many Thread objects are alive right now.

threading.activeCount()

Old camel case spelling.

Deprecated alias of threading.active_count. Call active_count instead.

threading.current_thread()

Returns the Thread object for the caller.

threading.currentThread()

Old camel case spelling.

Deprecated alias of threading.current_thread. Call current_thread instead.
