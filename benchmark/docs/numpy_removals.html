Migrating to the 2.0 series¶

This page lists names that no longer exist and what to write instead.

Main namespace

The following members were removed from the top level namespace.

Removed nameWhat to do
np.float_Removed in 2.0. Write np.float64 instead; it is the very same scalar type.
np.complex_Removed. Use np.complex128, the same double precision complex type.
np.NaNRemoved alias. The not-a-number constant is spelled np.nan in lower case.
np.InfRemoved alias. Positive infinity is np.inf in lower case.
np.inftyRemoved alias. Positive infinity is np.inf.
np.productRemoved. The function is called np.prod.
np.cumproductRemoved. The function is called np.cumprod.
np.sometrueRemoved. Use np.any, which has the same meaning.
np.alltrueRemoved. Use np.all, which has the same meaning.
np.round_Removed. Call np.round instead.
np.string_Removed. The bytes scalar type is np.bytes_.
np.unicode_Removed. The text scalar type is np.str_.
np.NINFRemoved. Negative infinity is written as -np.inf.
np.castRemoved. Convert with the astype method instead.
np.whoRemoved. Inspect variables with ordinary Python tools.
np.asfarrayRemoved. Use np.asarray with an explicit floating dtype.

Behaviour changes

Scalar printing changed: a float now prints with its type name. Update doctests accordingly.

  • Promotion rules for Python scalars changed.
  • Some default integer sizes changed on Windows.
