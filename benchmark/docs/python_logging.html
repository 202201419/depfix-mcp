logging module¶

Flexible event logging for applications.

logging.info(msg, *args, **kwargs)

Logs a message with level INFO on the root logger.

logging.warning(msg, *args, **kwargs)

Logs a message with level WARNING on the root logger.

logging.warn(msg, *args, **kwargs)

An old spelling kept for compatibility.

Deprecated alias of logging.warning. Call logging.warning with the same arguments.

logging.error(msg, *args, **kwargs)

Logs a message with level ERROR on the root logger.
