asyncio event loop¶

Event loop and task management.

asyncio.run(coro)

Runs a coroutine to completion and manages the event loop for you. Use it as the single entry point of a program.

asyncio.get_running_loop()

Returns the running loop. Raises RuntimeError when called outside a coroutine or callback.

asyncio.get_event_loop()

Returns the current loop.

Emits a deprecation warning when no loop is running. Inside coroutines call asyncio.get_running_loop. At the top level of a program prefer asyncio.run. The right choice depends on where the call sits.
