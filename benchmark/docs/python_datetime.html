datetime module¶

Classes for working with dates and times.

datetime.now(tz=None)

Returns the current local time. Pass a timezone such as timezone.utc to get an aware value.

datetime.utcnow()

Returns the current UTC time as a naive value.

Deprecated since 3.12. Prefer datetime.now(timezone.utc), which returns an aware value. When a naive value is still required, call .replace(tzinfo=None) on that result.

datetime.fromtimestamp(timestamp, tz=None)

Converts a POSIX timestamp. With a timezone argument the result is aware.

datetime.utcfromtimestamp(timestamp)

Converts a POSIX timestamp to a naive UTC value.

Deprecated since 3.12. Use datetime.fromtimestamp(timestamp, timezone.utc); add .replace(tzinfo=None) to keep the result naive.
