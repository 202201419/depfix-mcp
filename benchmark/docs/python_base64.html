base64 module¶

Encodings from RFC 4648.

base64.encodebytes(s)

Encodes bytes and returns bytes with line breaks inserted every 76 characters.

base64.encodestring(s)

Old name of encodebytes.

Removed in 3.9. Use base64.encodebytes with the same argument.

base64.decodebytes(s)

Decodes base64 bytes, ignoring line breaks.

base64.decodestring(s)

Old name of decodebytes.

Removed in 3.9. Use base64.decodebytes with the same argument.
